BeeShell

Every command.

What help shows in BeeCodersOs build 328: 87 entries, taken from the OS's own source (COMMANDS in kernel/src/shell.rs), so this page says what the OS says. Paths can be relative; "quotes" group words.

help
show this help
whoami, users
who is logged in; the accounts (none: no login, everyone may do everything)
useradd NAME [admin]
make an account (the first is an admin); userdel NAME; passwd [NAME]
login, logout
log in at the console / log out (with accounts, the console asks at boot)
clear
clear the screen (or Ctrl+L)
echo TEXT [> FILE]
print text, or write (>) / append (>>) to a file
ls [-s] [DIR]
list a directory (-s: files by size, largest first, and their total)
cd [DIR], pwd
change / show the current directory
cat FILE
show a file
A | B
what A prints goes to B (cat, head, tail, sort, wc, grep): ls | grep txt | sort
head|tail [-n N] FILE
the first / last N lines of a file (10 unless N is given)
wc FILE
count the lines, words and bytes of a file
sort [-r] [-u] FILE
the lines of a file in order (-r: last first, -u: each line once)
grep [-i] TEXT PATH
lines that contain TEXT, in a file or every file of a folder
touch FILE
create an empty file
mkdir DIR
create a directory (with parents)
rm PATH
remove a file or empty directory
mv FROM TO
move / rename
cp FROM TO
copy a file
tree [DIR]
show a directory tree
df
filesystem usage
du [FOLDER]
how much each entry takes (folders with all inside), largest first
find [FOLDER] TEXT
every path below FOLDER whose name contains TEXT (any case)
layout [us|be]
show / change the keyboard layout
history
previous commands (Up/Down to recall)
mem, about
memory usage, system info
calc EXPR
integer arithmetic: + - * / % ( )
date, uptime
current date and time (in the time zone, and UTC), time since boot
timezone [ZONE]
the time zone for date and the desktop clock: UTC, CET, +HH:MM (saved)
log [N]
last N events from the event log
wish TEXT
tell the OS what you'd like it to do
feedback TEXT
tell the OS what could be better
ask QUESTION
ask the AI (needs beehive on the host)
explain
ask the AI about the last error or crash
do TASK
the AI suggests commands for a task in plain words; they run if you say y
update [auto on|off]
fetch a new kernel from the AI host and put it on trial
ai control [on|off]
let the AI host run commands here and see the screen
ai connect HOST NAME KEY
reach beehive over the network (ai disconnect: stop)
ai [on|off]
AI bridge status; switch AI features on/off
selftest
run the kernel self-tests
net
network status; net dhcp | static IP/PREFIX [GW] | dns ADDR | off
ping [-c N] HOST
check that a machine answers
nslookup NAME
look up the address of a host name
nc HOST PORT [TEXT]
open a TCP connection: type lines, see the answers
httpd [on [PORT]|off]
status page for the local network (off by default)
fileserver [on [PORT]|off]
one folder for programs on the network, with a key (off by default); fileserver key [new], fileserver folder DIR
vnc [on|off|password]
remote desktop: see and use this screen from a VNC viewer (off by default; not encrypted)
remote [on|off]
remote shell with a password, not encrypted (off by default)
wget URL [FILE]
fetch a web address (http://): show it or save it
ntp [SERVER]
set the clock from a time server
tftp get|put HOST FILE
copy a file from / to a TFTP server
arp
neighbours learned on the local network
lspci [-v]
list PCI devices (-v: what each one can do)
install [DISK]
put the OS on a disk, or upgrade it (alone: list the disks)
timer DURATION [MESSAGE]
a kitchen timer (5m, 1h30m, 90s): a window and a tune when it is up; 'timer off N' cancels
alarm HH:MM [MESSAGE]
an alarm at the next HH:MM on the local clock: a window and a tune (it is a timer: 'timers', 'timer off N')
timers
the running timers and alarms, and what is left of them
cal [MONTH YEAR]
a month's calendar, weeks from Monday, today in [brackets]
lsusb
USB controller and devices
camera [raw|log]
USB cameras: the picture formats and sizes they offer ('raw': the description as the camera gave it; 'log': what the driver noted)
camera timelapse FILE.avi SECS [MIN]
a time-lapse video: a picture every SECS seconds, played back at 10 a second
camera watch FOLDER [MIN]
a security camera: saves a picture in FOLDER whenever something moves (Ctrl+C stops)
camera view
the camera live in a window, as in a mirror: s saves a picture, m mirrors, q leaves
camera on [WxH] | off
leave the camera sending (then 'camera' counts what arrives), or stop it
camera snap FILE [WxH]
take a picture with the USB camera (640x480 unless asked): JPEG, PNG or BMP by the name
camera record FILE.avi SECS
film with the USB camera into a Motion JPEG video (play it with 'play')
threads
what runs side by side inside the kernel
monitor
system monitor in a window: work per processor, memory, network, threads
view FILE|FOLDER
show a picture (JPEG, PNG, GIF, BMP or PPM) in a window; animated GIFs play; the arrow keys go through the folder's pictures
sound [volume N]
the sound card, its outputs and volume (0-100)
beep [HZ|NOTE [MS]]
play a tone (default 880 Hz, 300 ms; notes like a4, c#5)
play FILE.wav|.avi
play a WAV file, or a Motion-JPEG AVI video in a window
tune [save FILE.wav] NOTES
play notes like c5 e5 g5 c6:500 (r rests), or save them as a WAV file
record FILE.gif|.avi SECS
film the screen for SECS seconds (1-60): an animated GIF, or an MJPEG video
screenshot FILE
save the screen as a picture (FILE.jpg: JPEG, .png: PNG, .gif: GIF, otherwise BMP)
display [mode WxH]
screen: driver, resolution; 'display font 1|2|auto'; 'display test'; 'display speed'
edit FILE
text editor in a window on the desktop (Ctrl+S saves, Ctrl+Q leaves)
browse URL|FILE|WORDS
web page viewer in a window: http:// pages, HTML files, or a search; Tab/Enter/click follow links
files [FOLDER]
file manager in a window: browse, open in the editor, new folder, rename, delete
cpu [start|test|auto on|off]
the processor: name, how many, clock, features; start the others; measure; at boot or not (saved)
sleep SECONDS
wait (Ctrl+C ends it)
run FILE [WORDS]
the commands in FILE, line by line ($1..$9, $*: the WORDS); stops at the first that fails
terminal
one more terminal window on the desktop, with a shell of its own
desktop [on|off]
graphical desktop: the terminal in a window (on by default; saved); 'desktop wallpaper FILE|none'; 'desktop tile on|off' tiles the windows (saved)
slots
A/B kernel slots: which one runs, last trial
crash panic|exception|hang
deliberately crash the kernel: a panic, a CPU exception, or a hang the watchdog ends (tests crash reports)
reboot, shutdown
restart / power off

Desktop

Every key.

The desktop's keyboard shortcuts, as on Omarchy (KEYS in kernel/src/launcher.rs; Super+K shows them on the machine itself).

Super+Space
the launcher: programs by name
Super+Enter
a new terminal
Super+W
close the window
Super+arrows
go to the window that way
Super+Shift+arrows
swap the window with that one
Super+F
fill the screen, and back
Super+T
tile the windows, or let them float
Super+1-9
show another workspace
Super+Shift+1-9
send the window to a workspace
Super+K
these keys
Alt+Tab
the next window
Shift+PgUp/PgDn
look back in a terminal
Ctrl+C
stop a command
q / Esc
leave most windows
